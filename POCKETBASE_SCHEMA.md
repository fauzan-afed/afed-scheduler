## Collection Definitions

### 1. users Collection (Auth-enabled)

Replaces the localStorage-based user registration system.

| Field | Type | Required | Unique | Default | Notes |
|-------|------|----------|--------|---------|-------|
| id | text | ✓ | ✓ | auto | Auto-generated by PocketBase |
| email | email | ✓ | ✓ | | For authentication (optional) |
| name | text | ✓ | | | User's full name |
| department | select | ✓ | | | Department selection |
| gender | select | ✓ | | | Gender for avatar generation |
| avatarConfig | json | | | | Avatar configuration object |
| deviceId | text | | | | For tablet-based one-time registration |
| created | date | ✓ | | now | Auto-generated |
| updated | date | ✓ | | now | Auto-generated |

**Select Options:**
- `department`: `["Consumer", "Energy", "Tricipta", "Others"]`
- `gender`: `["male", "female"]`

**avatarConfig JSON Structure:**
```json
{
  "sex": "man" | "woman",
  "faceColor": "#F59E0B",
  "earSize": "small" | "big",
  "eyeStyle": "circle" | "oval" | "smile",
  "noseStyle": "round" | "long" | "pointing",
  "mouthStyle": "peace" | "smile" | "laugh" | "smirk",
  "skinStyle": "light" | "medium" | "dark",
  "hairStyle": "normal" | "thick" | "mohawk" | "womanLong" | "womanShort",
  "hairColor": "#FCD34D",
  "hatStyle": "none" | "beanie" | "turban" | "winter",
  "hatColor": "#F87171",
  "eyeBrowStyle": "up" | "natural" | "angry" | "sad",
  "shirtStyle": "hoody" | "short" | "sweater",
  "shirtColor": "#67E8F9",
  "glassesStyle": "none" | "round" | "sunglass" | "design",
  "bgColor": "#E0F2FE"
}
```

**Auth Settings:**
- Enable email/password authentication
- Disable email verification (for internal use)
- Allow only email-based auth (no OAuth needed)

### 2. rooms Collection

Manages meeting room information and 3D model references.

| Field | Type | Required | Unique | Default | Notes |
|-------|------|----------|--------|---------|-------|
| id | text | ✓ | ✓ | auto | Auto-generated |
| name | text | ✓ | ✓ | | e.g., "Operation 133" |
| modelPath | text | | | | Path to 3D model file (e.g., "/model.gltf") |
| capacity | number | | | | For future filtering (default: 10) |
| floorLevel | text | | | | For multi-floor support (e.g., "1F", "2F") |
| isActive | bool | ✓ | | true | Soft delete / active status |
| created | date | ✓ | | now | Auto-generated |
| updated | date | ✓ | | now | Auto-generated |

---

### 3. meetings Collection

Stores all meeting bookings with time range and ownership tracking.

| Field | Type | Required | Unique | Default | Notes |
|-------|------|----------|--------|---------|-------|
| id | text | ✓ | ✓ | auto | Auto-generated |
| room | relation | ✓ | | | Relates to `rooms` collection |
| owner | relation | ✓ | | | Relates to `users` collection (creator) |
| title | text | ✓ | | | Meeting title |
| start | date | ✓ | | | Meeting start time (ISO 8601) |
| end | date | ✓ | | | Meeting end time (ISO 8601) |
| status | select | ✓ | | scheduled | Meeting status |
| remark | text | | | | Optional notes/description |
| created | date | ✓ | | now | Auto-generated |
| updated | date | ✓ | | now | Auto-generated |

**Select Options:**
- `status`: `["scheduled", "cancelled", "completed"]`

**Validation Rules:**
- `end > start` (end time must be after start time)
- Business hours validation: 8 AM - 6 PM (enforced via hooks)
- Weekend restriction (enforced via hooks)

---

### 4. meeting_attendees Collection (Junction Table)

Many-to-many relationship between meetings and attendees. Supports both registered users and external attendees.

| Field | Type | Required | Unique | Default | Notes |
|-------|------|----------|--------|---------|-------|
| id | text | ✓ | ✓ | auto | Auto-generated |
| meeting | relation | ✓ | | | Relates to `meetings` |
| user | relation | | | | Relates to `users` (null for external) |
| name | text | ✓ | | | Display name |
| avatar | text | | | | External avatar URL (legacy support) |
| avatarConfig | json | | | | Avatar config for registered users |
| isExternal | bool | ✓ | | true | true if not a registered user |
| created | date | ✓ | | now | Auto-generated |

**Logic:**
- If `user` is set → registered user, use `user.name` and `user.avatarConfig`
- If `user` is null → external attendee, use `name` and `avatar` fields

## API Rules & Access Control

### users Collection

```
# List/Search
id = @request.auth.id

# View
id = @request.auth.id

# Create
id != "" && deviceId != ""  # Allow registration with deviceId

# Update
id = @request.auth.id

# Delete
id = @request.auth.id
```

**Rules:** Users can only view/edit their own profile. Registration requires a `deviceId`.

---

### rooms Collection

```
# List
id != ""  # Public read

# View
id != ""  # Public read

# Create
@request.auth.id != "" && @request.auth.role = "admin"

# Update
@request.auth.id != "" && @request.auth.role = "admin"

# Delete
@request.auth.id != "" && @request.auth.role = "admin"
```

**Rules:** Public read access, admin-only write access.

---

### meetings Collection

```
# List
room.isActive = true

# View
room.isActive = true

# Create
@request.auth.id != "" && start >= @now && end > start

# Update
owner = @request.auth.id

# Delete
owner = @request.auth.id
```

**Rules:**
- Only authenticated users can create meetings
- Only meeting owners can update/delete their meetings
- Only show meetings for active rooms

---

### meeting_attendees Collection

```
# List
meeting.room.isActive = true

# View
meeting.room.isActive = true

# Create
@request.auth.id != "" && meeting.owner = @request.auth.id

# Update
meeting.owner = @request.auth.id

# Delete
meeting.owner = @request.auth.id
```

**Rules:** Only meeting owners can manage attendees.

## PocketBase Hooks (Go Extensions)

### Conflict Detection Hook

```go
// hooks/meetings.go
package hooks

import (
    "github.com/pocketbase/pocketbase/core"
    "github.com/pocketbase/pocketbase/tools/types"
)

func OnMeetingBeforeCreate(e *core.RecordEvent) error {
    meeting := e.Record

    // Check for time conflicts
    records, err := e.App.FindRecordsByFilter(
        "meetings",
        "room = {:roomId} && start < {:end} && end > {:start} && status != 'cancelled'",
        nil,
        0,
        0,
        nil,
        types.Params{
            "roomId": meeting.GetStringValue("room"),
            "start":  meeting.GetStringValue("start"),
            "end":    meeting.GetStringValue("end"),
        },
    )
    if err != nil {
        return err
    }

    if len(records) > 0 {
        return e.App.Err(errors.New("meeting time conflict detected"))
    }

    // Business hours validation (8 AM - 6 PM)
    start := meeting.GetDateTime("start").Time()
    end := meeting.GetDateTime("end").Time()

    // Check weekend
    if start.Weekday() == time.Saturday || start.Weekday() == time.Sunday {
        return e.App.Err(errors.New("meetings cannot be booked on weekends"))
    }

    // Check business hours (8:00 - 18:00)
    if start.Hour() < 8 || start.Hour() >= 18 || end.Hour() > 18 || (end.Hour() == 18 && end.Minute() > 0) {
        return e.App.Err(errors.New("meetings must be within 8:00 AM - 6:00 PM"))
    }

    return nil
}

func OnMeetingBeforeUpdate(e *core.RecordEvent) exception {
    // Same validation, excluding current record
    meeting := e.Record

    records, err := e.App.FindRecordsByFilter(
        "meetings",
        "room = {:roomId} && start < {:end} && end > {:start} && status != 'cancelled' && id != {:id}",
        nil,
        0,
        0,
        nil,
        types.Params{
            "roomId": meeting.GetStringValue("room"),
            "start":  meeting.GetStringValue("start"),
            "end":    meeting.GetStringValue("end"),
            "id":     meeting.Id,
        },
    )
    // ... same conflict checks
}

// Register hooks in main.go
func RegisterHooks(app *core.Application) {
    app.OnRecordBeforeCreate("meetings").Bind(&OnMeetingBeforeCreate)
    app.OnRecordBeforeUpdate("meetings").Bind(&OnMeetingBeforeUpdate)
}
```

### Device ID Uniqueness Hook

```go
// hooks/users.go
package hooks

func OnUserBeforeCreate(e *core.RecordEvent) error {
    deviceId := e.Record.GetStringValue("deviceId")

    if deviceId != "" {
        existing, err := e.App.FindRecordsByFilter(
            "users",
            "deviceId = {:deviceId}",
            nil,
            1,
            0,
            nil,
            types.Params{"deviceId": deviceId},
        )
        if err != nil {
            return err
        }
        if len(existing) > 0 {
            return e.App.Err(errors.New("device already registered"))
        }
    }

    return nil
}
```

## Query Examples

### Get Meetings for a Specific Date and Room

```javascript
import pb from '@/lib/pocketbase';

const roomId = "ROOM_ID";
const startDate = "2026-01-12T00:00:00Z";
const endDate = "2026-01-13T00:00:00Z";

const result = await pb.collection('meetings').getList(1, 50, {
  filter: `room = "${roomId}" && start >= "${startDate}" && start < "${endDate}" && status != "cancelled"`,
  sort: '+start',
  expand: 'owner,room'
});

// Access expanded relations
const meetings = result.items.map(m => ({
  ...m,
  owner: m.expand.owner,
  room: m.expand.room
}));
```

### Check for Conflicts

```javascript
const startTime = "2026-01-12T10:00:00Z";
const endTime = "2026-01-12T11:00:00Z";

const conflicts = await pb.collection('meetings').getList(1, 1, {
  filter: `room = "${roomId}" && start < "${endTime}" && end > "${startTime}" && status != "cancelled" && id != "${excludeId}"`
});

if (conflicts.totalItems > 0) {
  console.log("Conflict detected:", conflicts.items[0].title);
}
```

### Create Meeting with Attendees

```javascript
// 1. Create the meeting
const meeting = await pb.collection('meetings').create({
  room: roomId,
  owner: pb.authStore.model.id,
  title: "Weekly Sync",
  start: "2026-01-12T10:00:00Z",
  end: "2026-01-12T11:00:00Z",
  status: "scheduled"
});

// 2. Add attendees
await pb.collection('meeting_attendees').create({
  meeting: meeting.id,
  user: userId, // null for external
  name: "John Doe",
  isExternal: false
});
```

### Get Meeting with Attendees

```javascript
const meeting = await pb.collection('meetings').getOne(meetingId, {
  expand: 'owner,room'
});

// Get attendees
const attendees = await pb.collection('meeting_attendees').getList(1, 50, {
  filter: `meeting = "${meetingId}"`,
  expand: 'user'
});
```

### Register User (Device-based)

```javascript
const userData = await pb.collection('users').create({
  email: "tablet-device@example.com", // optional
  password: "random-password", // optional
  passwordConfirm: "random-password",
  name: "John Doe",
  department: "Consumer",
  gender: "male",
  avatarConfig: avatarConfig, // JSON object
  deviceId: "device-unique-id"
});

// Auto-login
await pb.collection('users').authWithPassword(
  "tablet-device@example.com",
  "random-password"
);
```

### Real-time Subscription

```javascript
// Subscribe to meeting changes for a room
pb.collection('meetings').subscribe('*', (e) => {
  const record = e.record;

  // Check if it's for our room
  if (record.room === roomId) {
    switch (e.action) {
      case 'create':
        console.log('New meeting:', record.title);
        break;
      case 'update':
        console.log('Meeting updated:', record.title);
        break;
      case 'delete':
        console.log('Meeting deleted:', record.title);
        break;
    }
  }
});

// Unsubscribe
pb.collection('meetings').unsubscribe();
```

## Implementation Guide

### Step 1: Initialize PocketBase

```bash
# Create new PocketBase project
mkdir afed-scheduler-pb && cd afed-scheduler-pb
pocketbase serve
```

Access admin UI at `http://127.0.0.1:8090/_/`

### Step 2: Install Dependencies

```bash
# In your Next.js project
npm install pocketbase
# or
yarn add pocketbase
# or
pnpm add pocketbase
```

### Step 3: Environment Variables

Create `.env.local`:
```env
NEXT_PUBLIC_POCKETBASE_URL=http://127.0.0.1:8090
```

### Step 4: Create PocketBase Client

```typescript
// lib/pocketbase.ts
import PocketBase from 'pocketbase';

const pb = new PocketBase(
  process.env.NEXT_PUBLIC_POCKETBASE_URL || 'http://127.0.0.1:8090'
);

// Disable auto-refresh for simpler auth (optional)
pb.autoCancellation(false);

export default pb;
```

### Step 5: Create Collections via Admin UI

1. Access `http://127.0.0.1:8090/_/`
2. Create collections in order:
   - **users** (Settings → Auth: enable email/password auth)
   - **rooms**
   - **meetings**
   - **meeting_attendees**

### Step 6: Migrate Existing Data (Optional)

```javascript
// scripts/migrate-localstorage.js
import pb from '@/lib/pocketbase';

// Migrate local user
const localUser = localStorage.getItem('currentUser');
if (localUser) {
  const user = JSON.parse(localUser);

  // Create room if not exists
  const room = await pb.collection('rooms').getFirstListItem('name = "Operation 133"', {
    filter: 'name = "Operation 133"'
  });

  // Create user
  await pb.collection('users').create({
    email: `${user.id}@temp.com`,
    password: 'temp123',
    passwordConfirm: 'temp123',
    name: user.name,
    department: user.department,
    gender: user.gender,
    avatarConfig: user.avatarConfig,
    deviceId: user.id
  });
}
```

### Step 7: Update Components

| Component | Change |
|-----------|--------|

## Type Definitions

Create `types/pocketbase.ts`:

```typescript
import { AvatarFullConfig } from 'react-nice-avatar';

// PocketBase Record Response Wrapper
export interface PbResponse<T> {
  id: string;
  collectionId: string;
  collectionName: string;
  created: string;
  updated: string;
  [key: string]: any;
}

// User Record
export interface PbUser extends PbResponse<{
  email?: string;
  name: string;
  department: 'Consumer' | 'Energy' | 'Tricipta' | 'Others';
  gender: 'male' | 'female';
  avatarConfig: AvatarFullConfig;
  deviceId?: string;
}> {}

// Room Record
export interface PbRoom extends PbResponse<{
  name: string;
  modelPath?: string;
  capacity?: number;
  floorLevel?: string;
  isActive: boolean;
}> {}

// Meeting Record
export interface PbMeeting extends PbResponse<{
  room: string; // relation ID
  owner: string; // relation ID
  title: string;
  start: string; // ISO 8601
  end: string; // ISO 8601
  status: 'scheduled' | 'cancelled' | 'completed';
  remark?: string;
}> {}

// Meeting with Expansions
export interface PbMeetingExpanded extends PbResponse<{
  room: PbRoom;
  owner: PbUser;
  title: string;
  start: string;
  end: string;
  status: 'scheduled' | 'cancelled' | 'completed';
  remark?: string;
}> {}

// Meeting Attendee Record
export interface PbMeetingAttendee extends PbResponse<{
  meeting: string; // relation ID
  user?: string; // relation ID (null for external)
  name: string;
  avatar?: string; // external avatar URL
  avatarConfig?: AvatarFullConfig;
  isExternal: boolean;
}> {}

// Meeting Attendee with Expansion
export interface PbMeetingAttendeeExpanded extends PbResponse<{
  meeting: PbMeeting;
  user?: PbUser;
  name: string;
  avatar?: string;
  avatarConfig?: AvatarFullConfig;
  isExternal: boolean;
}> {}

// List Response
export interface PbListResponse<T> {
  page: number;
  perPage: number;
  totalItems: number;
  totalPages: number;
  items: T[];
}

// Auth Store
export interface PbAuthStore {
  token: string;
  model: PbUser | null;
}

// Convert PocketBase Meeting to App Meeting
export function pbToAppMeeting(pbMeeting: PbMeetingExpanded, attendees: PbMeetingAttendeeExpanded[]) {
  return {
    id: pbMeeting.id,
    ownerId: pbMeeting.owner.id,
    title: pbMeeting.title,
    start: new Date(pbMeeting.start),
    end: new Date(pbMeeting.end),
    attendees: attendees.map(a => ({
      id: a.user?.id || a.id,
      name: a.name,
      avatarConfig: a.avatarConfig,
      avatar: a.avatar
    }))
  };
}

// Convert App Attendee to PocketBase
export function appToPbAttendee(meetingId: string, userId?: string, name: string, avatarConfig?: AvatarFullConfig) {
  return {
    meeting: meetingId,
    user: userId || null,
    name: name,
    avatarConfig: avatarConfig || null,
    isExternal: !userId
  };
}
```
